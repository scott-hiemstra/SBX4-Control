sbx4-control APT repository

Packages of sbx4-control, a control panel for the Creative Sound Blaster X4, for Ubuntu 22.04+ and Debian 12+ (amd64).

Set up once

sudo install -d /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/sbx4-control.asc https://scott-hiemstra.github.io/SBX4-Control/sbx4-control.asc
sudo curl -fsSLo /etc/apt/sources.list.d/sbx4-control.sources https://scott-hiemstra.github.io/SBX4-Control/sbx4-control.sources
sudo apt update
sudo apt install sbx4-control

After that, sbx4-control also appears in GNOME Software and Discover, and updates arrive with your normal system updates.
